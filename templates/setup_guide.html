INTRANET PRIVADA

Prepara el acceso del equipo.

La primera cuenta administradora se crea desde la consola del servidor. Después podrás gestionar los usuarios desde el programa.

Si el programa ya está instalado

  1. Abre la consola de tu hosting y entra en la carpeta del programa.
  2. Ejecuta este comando con el entorno de Python de tu instalación:
    .venv/bin/flask --app app create-admin --username mario --name "Mario Portugal"
  3. Escribe y confirma una contraseña de al menos 10 caracteres cuando la consola la solicite. La contraseña se introduce de forma oculta.
  4. Recarga el programa en el panel del hosting y entra con el usuario que creaste.

El programa no tiene una contraseña predeterminada ni permite registrar públicamente la primera cuenta. En Docker, usa la consola del contenedor indicada en la guía completa.

Si todavía no tienes hosting

Puedes comenzar con una cuenta de PythonAnywhere, que ofrece un plan gratuito con límites de uso. La guía completa explica cómo subir el ZIP, instalar las dependencias y activar el sitio.

Para otro proveedor, elige un hosting que permita Python 3.10 o superior y aplicaciones WSGI. En cPanel, busca la opción Setup Python App o su equivalente. Un servicio que solo ejecute PHP o archivos HTML necesita otra implementación.

Instala el programa en la raíz de un subdominio, activa HTTPS y conserva la base de datos en almacenamiento permanente fuera de la carpeta de archivos públicos.

Después de entrar

  1. Usa Importar Excel para cargar los casos.
  2. Abre Usuarios y crea las cuentas del equipo. Los colaboradores consultan los casos y registran actuaciones y tareas; los administradores también gestionan las cuentas.
  3. Comparte la dirección HTTPS que te entregue el hosting. Cada persona entrará con su propio usuario y contraseña.

Los nuevos registros muestran el nombre de la cuenta que los realizó. Los datos y autores históricos del Excel se conservan.
